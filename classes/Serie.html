    Class Serie

    Solves a whole series of related equilibria.

    Each point is warm-started from the previous solution, which is both much faster and much more stable than solving every point from scratch.

    • getSolutions(options: SweepOptions): SweepResult

      Sweep one species and solve the equilibrium at every value of it.

      With varying: 'H+', isFixed: true and log: true this produces the classic speciation diagram against pH.

      Parameters

      • options: SweepOptions

        What to sweep, over which range, and how finely.

      Returns SweepResult

      The swept values and the speciation at each of them.

      Throws

      When to is not greater than from, or varying is missing.
